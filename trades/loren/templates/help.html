Help

Quick setup for Telegram signals and Pocket Option copy trading.

Getting started
  1. Telegram API — Get API ID and hash from my.telegram.org, save under Settings → Telegram, then log in with your phone.
  2. Channels — Add each signal group on Channels. Pick the parser (Lorenzo, BinaryAnalyst, MT5 alert, etc.), timezone, and platform.
  3. Pocket Option — Paste SSID under Settings → Platforms, use Test all connections, then Test Trade with a small amount.
  4. Start bot — On the Dashboard, press Start. Signals appear in Signal Inbox; trades run at scheduled entry times.
  5. Monitor — Use Activity Logs and Trade History to verify behavior.
FAQ
Should “Monitor all Telegram chats” be on?

Leave it off. Only channels you add under Channels are traded. Turning it on listens to every chat (not recommended).

Signals detected but no trades?

Check channel Auto-trade is on, platform is connected, entry time is valid, and bot is Running on the Dashboard.

MT5 / Deriv text-only channels?

Use parser “MT5 text” with platform “None” for alerts only — no automatic orders.

Telegram “two different IP” error?

Use one server session only. Re-login under Settings → Telegram if the session was used elsewhere.
